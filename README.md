# Parqis In Pixel Perfection

# PROFESSIONAL WEBSITE CLONING TASK

I am participating in a website cloning competition. Your task is to recreate the provided reference website with maximum visual accuracy and functional completeness.

REFERENCE WEBSITE:
https://parqis.com/

I will also provide screenshots of the original website for accurate visual reference.

## 1. Website Analysis

Before writing code, carefully analyze the reference website.

Identify:
- Complete website structure and page sections.
- Header, navigation bar and hero section.
- Typography, font families and font weights.
- Primary, secondary and background colors.
- Image sizes, positioning and aspect ratios.
- Margins, padding, spacing and alignment.
- Buttons, cards, borders and shadows.
- Footer structure.
- Animations, transitions and interactions.

Do not start with a generic website template.

## 2. Design Recreation

Recreate the website as it shown exactly copy possible.

Requirements:
- Maintain the original visual identity.
- Match the original layout and proportions.
- Reproduce the same section ordering.
- Use accurate typography and color combinations.
- Maintain consistent spacing and alignment.
- Use original images and icons wherever accessible.
- Recreate the original navigation and footer.
- Avoid unnecessary gradients, excessive animations or decorative elements.

## 3. Technical Development

Use:
- React
- TypeScript
- Tailwind CSS
- Lucide icons where appropriate.

Write clean, reusable and maintainable components.

Organize the code into logical sections and components rather than putting everything in one file.

## 4. Functional Requirements

Make all visible elements functional:
- Navigation links.
- Search functionality if present.
- Dropdown menus.
- Buttons and call-to-action elements.
- Forms and input fields.
- Tabs and interactive cards.
- Mobile navigation menu.

Do not leave decorative buttons that do nothing.

## 5. Responsive Design

The website must work perfectly on:
- Desktop computers.
- Laptops.
- Tablets.
- Android phones.
- iPhones.

Ensure:
- No horizontal overflow.
- Images scale correctly.
- Navigation adapts to smaller screens.
- Text remains readable.
- Sections maintain appropriate spacing.

## 6. Visual Accuracy

Visual similarity is the highest priority.

Compare the recreated website against the reference screenshots.

Pay special attention to:
- Header height.
- Container width.
- Hero image dimensions.
- Font sizes.
- Section spacing.
- Image positioning.
- Card dimensions.
- Button sizes.
- Footer alignment.

Do not invent sections or change the original design.

## 7. Quality Testing

Before completion:
- Check all images and assets.
- Verify all navigation links.
- Test interactive components.
- Check browser console errors.
- Test desktop and mobile layouts.
- Fix broken elements.
- Verify that the website runs correctly.

## 8. Final Instruction

First analyze the reference website and create a complete implementation plan.

Then build the entire homepage, including all visible sections.

Do not stop after creating the header and hero section.

Do not unnecessarily redesign the website.

FINAL GOAL:

Deliver a polished, professional and fully responsive website clone that closely matches the original website in appearance, layout and functionality.

Prioritize accuracy over creativity.
